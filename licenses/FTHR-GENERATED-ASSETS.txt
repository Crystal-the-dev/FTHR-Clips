FTHR Clips generated release assets
===================================

Copyright (c) 2026 FTHR-Community

The project logos, application icon, UI icons, installer artwork, repository
social preview, and notification WAV files listed in
tools/release_asset_manifest.json are generated solely by
tools/generate_release_assets.py.

The generator uses simple geometric primitives, an original compact bitmap
alphabet, and synthesized sine tones. It does not use an external image, icon
set, sound sample, system font, or other third-party creative-media input.
